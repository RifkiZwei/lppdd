Fase 1: Pengenalan Konsep VPS & Cloud

Jelaskan secara singkat pemahaman mengenai perbedaan layanan berikut.

Shared Hosting

Satu server digunakan bersama oleh banyak pengguna. Sumber daya seperti CPU, RAM, dan penyimpanan dibagi, sehingga biaya lebih murah tetapi kontrol server terbatas.

Dedicated Server

Satu server fisik disediakan khusus untuk satu pengguna. Kinerja dan kontrol lebih besar, tetapi biaya serta tanggung jawab pengelolaannya juga lebih tinggi.

Amazon Lightsail

Layanan VPS sederhana dari AWS dengan paket harga dan sumber daya yang mudah dipilih. Cocok untuk website atau aplikasi skala kecil hingga menengah.

Amazon EC2

Layanan komputasi cloud AWS yang menyediakan server virtual dengan pilihan konfigurasi luas. Pengguna dapat mengatur tipe instance, jaringan, penyimpanan, dan skalanya.

Fase 2: Persiapan dan Provisioning Server

Beri tanda centang setelah tahapan benar-benar berhasil dilakukan di konsol AWS.

Penting: Manajemen Key Pair
File berakhiran .pem atau .ppk merupakan kunci untuk mengakses server. Simpan secara aman dan jangan membagikannya. Jika hilang, akses SSH dapat terganggu.

Catatan: nama Key Pair dan checklist praktik harus diisi berdasarkan tindakan yang benar-benar dilakukan.

Perintah SSH dari terminal lokal

Ganti nama file key dan alamat IP dengan data server AWS milikmu.

ssh -i "nama-key.pem" ubuntu@IP-PUBLIK-EC2

Tugas Praktik Web Server

1. Instal Apache atau Nginx pada server.
2. Buat file index.html kustom di direktori /var/www/html/.
3. Buka IP Publik server melalui browser.

Alamat di atas diisi setelah web server berhasil diakses. Jangan menggunakan alamat contoh sebagai hasil praktik.

Fase 6: Manajemen, Monitoring & Backup

Pemeliharaan server penting untuk menjaga ketersediaan layanan. Gunakan AWS CloudWatch untuk melihat status server dan catat hasil aktual.

Catat Metrik Server Saat Ini (CloudWatch)

Langkah Backup (Snapshot)

  1. Buka menu Volumes di konsol EC2.
  2. Pilih Volume server.
  3. Klik Actions > Create Snapshot.
  4. Beri deskripsi dan simpan.

Nilai CPU dan Status Check berbeda-beda sesuai kondisi instance. Ambil dari CloudWatch, jangan mengarang angka.
